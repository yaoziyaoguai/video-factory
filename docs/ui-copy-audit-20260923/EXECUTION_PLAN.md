- 只改用户能看到的文案与展示投影，不改费用计算、授权范围、模型调用、重试、发布或人工确认的行为。

- 保留已有工作树改动；不提交、推送或部署；本轮不发起真实模型、付费素材或平台发布。
- `NEEDS_CONTRACT_CHECK` 先读实际共享类型、处理器和测试。无法证实的建议不实施，并在结果中列出。

1. 共用投影：COPY-06/07/08/10/11/12/16/17/20/21/23，COPY-22 核对单位后处理。先加失败用例，后改 `presentation.ts`、`NodeDeliveryPreview.tsx`、`NodeStructuredEditor.tsx`。验收：自由原文不变；未知值不冒充已知；停止状态不说进行中；所有已允许展示的候选和字段可展开；未扩大字段白名单。
2. 费用/恢复/人工决定：COPY-01～05/09/13～15/18/19/28。先核对状态合同及 handler，再改对应组件固定文案。验收：按钮说明与副作用一致，金额性质常驻可见，未知扣费不诱导重复任务，向导体现每个关键人工停点。
