## 必须回答的设计问题

1. 新人进入后，是否能知道从哪里开始、自己拥有什么控制权、现在正在做什么、下一步会不会花钱？

3. 新建制作的信息逐步展开如何设计？保留所有已有字段/用户显式选择，不通过删字段或静默默认换取简洁。未保存输入、失焦、重开弹窗、请求中/失败、长文本都要考虑。
4. 配置页如何让模型接入与角色默认一眼分清？素材库如何以媒体为主体，仍让来源、许可、复用记录可追踪？
5. 中文阅读、字体、密度、颜色对比、控件尺寸、边框、阴影、留白、图标、选中与焦点态，怎样统一且好看？选择一个可落地的方向，并给出 1440×900、768×1024、390×844 布局。320/375/200% 放大作为边界检查，不凭截图说已通过。
6. 动效需要可感知的提升：页面/导航切换、当前节点交接、讨论消息和提案、素材卡预览、面板展开、成片完成反馈。逐条给 trigger、元素、property、duration、easing、stagger、取消/重入/卸载、reduced-motion、性能和 QA 方法。至少 2 个克制但有记忆点的“招牌动效”，不能整屏长期粒子/跑马灯、自动播放声音、伪造进度、滚动劫持、为了动画禁用按钮，也不能把所有效果削成静态。高频输入/错误/付款确认区域必须克制。
7. 多层 CSS 覆盖怎样在最小范围内理清，而不是在最后再加第四套互相覆盖的皮肤？明确哪些现有规则改、哪些迁移、加载顺序、回归面。禁止无关重构巨型文件。
