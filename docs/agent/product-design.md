# 从一段对话到一条成片

**会话不是视频。** 一条会话可以包含闲聊、热点研究、几件互不相关的作品；索要提示词只是普通回答。用户明确要开始制作某件作品后，才为它准备阶段草稿。等待用户认可时没有倒计时，仍可在同一窗口做别的事。

以下表格描述通用基础路径，不是所有视频都必须经过的固定流程。2026-11-08 四阶段增量已实现下文的分组审阅并通过六旅程验收（见 [当前记录](CURRENT.md)）；日常实例尚未换版，线上版本以部署记录为准。

| 用户正在看什么 | 用户可以做什么 | 何时进入确认区 |
| --- | --- | --- |
| 内容草稿 | 讨论结构、台词、素材，针对当前版本修改 | 认可该版内容时 |
| 画面与声音方案 | 按镜头检查画面、原声、配音、音乐；可以只认可，也可以继续询价 | 认可该版方案时；询价不等于付费制作 |
| 制作提案 | 看输入、产出、型号、估价与本次授权，确认或放弃 | 提案是制作许可，不是成品 |
| 片段与视频草稿 | 预览、指定片段修改，核对受影响的文稿与方案；讨论其他版本 | 对具体版本明确认可后；完成生成本身不等于认可 |
| 作品库 | 回放已确认的最终视频，回到来源对话并查看对应修订 | 以已确认视频为入口 |

左侧导航切换会话与设置，中间聊天，右侧查看作品。草稿与已确认成果分别展示，点历史卡片不能把旧稿变成当前成果。多个作品各自推进；其中一件产生新稿，不会替另一件完成确认。已受理的制作锁定所用版本，后续修改用于新提案。

文本、图片、视频、配音各有一个当前型号，可以保留备选；有推理档位的文本型号可以选择档位。Skill 可以由 Pi 依据上下文使用，用户也可以指定。热点榜用于发现趋势，不授予榜单商业音乐的下载或使用许可；要用作配乐，需采用可下载且授权适合的音轨。

## 已实施：围绕实际产出审阅（2026-11-08）

Agent 根据目标、已有素材和预算选择素材剪辑、代码动画、模型生成或混合方式。Skill 提供专业方法，执行工具提供真实能力；不为每类题材建立一条固定向导，也不把外部 Skill 的自动评分、审计和反复改稿变成产品必经步骤。

每次准备好一组值得用户查看的产出再停下来。组可以是角色图、背景图和分镜，也可以是配音、片段或成片。用户可以只认可其中一项；确认区立即出现那一项的准确版本，其他内容继续在草稿区。整组认可不等于自动进入下一步；“认可并继续”是明确的另一种用户意图。内部临时文件和工具调用不逐项要求确认。

用户可以在未认可整组时说“先看看这个人物走路”。Agent 只做这个范围的短预览，结果仍是草稿，不顺带认可背景或制作整片；新增付费调用仍需明确费用许可。用户也可以随时聊其他话题或开始另一件作品。

针对图片或视频片段的修改应让模型看到相应实际图像/帧，同时读取可编辑源文件。音频转写、信号分析与听感理解分开说明；没有实际输入或不支持的能力不能声称已经看过、听过。独立审查只在用户要求时做。

最终视频通过“定稿并入库”进入作品库，保留该版制作时的内容、方案、角色/场景图、音轨、片段、源码和时间线。普通认可不自动入库，定稿也不重新采集最新工程。保存文件不等于认可文件，用在成片中不自动补造一条认可记录。未采用的候选留在原对话草稿，已确认历史版本不被后续修改覆盖。

实际制作所用素材与本次需要认可的创作依据分别记录。已认可依据产生的内部代码和中间文件不逐个求认可；局部试做也不能把未认可的必要背景悄悄带进正式制作。免费代码渲染保存真实任务和来源，不显示零元预算卡；后台完成发布草稿后等待用户，聊天仍可讨论别的事。

输入框提供“从作品库选择”，把已有作品的素材带入新对话；勾选只是准备引用，发送后仍可先讨论。修改产生新版本，原视频及其来源不变。本增量不提供外部文件上传、外链导入或仿拍参考入口。
