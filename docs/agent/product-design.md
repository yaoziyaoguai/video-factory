# 从一段对话到一条成片

**会话不是视频。** 一条会话可以包含闲聊、热点研究、几件互不相关的作品；索要提示词只是普通回答。用户明确要开始制作某件作品后，才为它准备阶段草稿。等待用户认可时没有倒计时，仍可在同一窗口做别的事。

| 用户正在看什么 | 用户可以做什么 | 何时进入确认区 |
| --- | --- | --- |
| 内容草稿 | 讨论结构、台词、素材，针对当前版本修改 | 认可该版内容时 |
| 画面与声音方案 | 按镜头检查画面、原声、配音、音乐；可以只认可，也可以继续询价 | 认可该版方案时；询价不等于付费制作 |
| 制作提案 | 看输入、产出、型号、估价与本次授权，确认或放弃 | 提案是制作许可，不是成品 |
| 片段与视频草稿 | 预览、指定片段修改，核对受影响的文稿与方案；讨论其他版本 | 对具体版本明确认可后；完成生成本身不等于认可 |
| 作品库 | 回放已确认的最终视频，回到来源对话并查看对应修订 | 以已确认视频为入口 |

左侧导航切换会话与设置，中间聊天，右侧查看作品。草稿与已确认成果分别展示，点历史卡片不能把旧稿变成当前成果。多个作品各自推进；其中一件产生新稿，不会替另一件完成确认。已受理的制作锁定所用版本，后续修改用于新提案。

文本、图片、视频、配音各有一个当前型号，可以保留备选；有推理档位的文本型号可以选择档位。Skill 可以由 Pi 依据上下文使用，用户也可以指定。热点榜用于发现趋势，不授予榜单商业音乐的下载或使用许可；要用作配乐，需采用可下载且授权适合的音轨。
