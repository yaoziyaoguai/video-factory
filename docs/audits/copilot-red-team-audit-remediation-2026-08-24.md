## 已确认但未在本轮冒充解决

1. **Git 交付**：审计指出 Web Studio 大量文件仍为 untracked，这个判断成立。当前工作区还包含既有未提交改动；本轮未擅自 `git add/commit/push`。在换机、clone 或协作前必须形成可审查提交。
2. **付费真实账本与远端取消**：当前只有预计单价、单次 brief 预算和调用前门禁，没有厂商实际账单回填、跨 run 消费账本或超时后的远端任务取消。在这三项完成前，付费 Provider 默认关闭，不把预计成本解释为账单保证。
3. **审片后的异步续跑**：并发冲突语义已修复，但批准请求仍在文件锁内同步完成发布包节点。当前节点短且本地可控；在人工节点前移或加入慢节点前，应改为“落决定后异步续跑”。
4. **Provider 单一事实源**：服务端预检、Pipeline worker 参数和付费 Adapter 仍各自拥有一部分注册信息。测试 Provider 泄漏已封堵，但新增正式 Provider 时仍需要跨模块一致性检查；后续应提取共享 executable-provider manifest。
5. **列表自动刷新**：实时承诺已限定到制作详情页。制作记录、首页统计和实验统计仍是进入页面时读取，需要刷新页面获取后台变化。
6. **公开部署安全**：当前只绑定 `127.0.0.1`，没有账号鉴权、Host 校验和面向公网的安全头基线。改变绑定地址或对外部署前必须单独做安全门禁。
7. **可重复浏览器套件**：本轮继续做真实浏览器验收，但仓库尚无可在 CI 运行的 Playwright 测试文件；历史结果文档已明确它们是一次性会话证据。
