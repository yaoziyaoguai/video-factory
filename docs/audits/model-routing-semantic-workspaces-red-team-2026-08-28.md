# 模型路由、语义工作台与付费闸门红队审计

- 审计日期：2026-08-28
- 审计范围：动态模型路由、参考视频制作语法、素材语义排序、节点输入输出编辑、付费前确认、资源与成本治理
- 审计原则：不把配置存在等同于能力可用；不把估算费用写成供应商账单；不在免费验证完成前触发付费生成

## 已发现并修复

1. **启动幂等性受全局默认模型漂移影响**：客户端重试的原始请求相同，但服务端原先用解析后的默认模型计算摘要。现改为用原始用户请求做幂等摘要，模型默认值只在首次创建时解析；新增“默认值变化后仍回放原任务”的回归测试。
2. **Seedance 2.5 能力声明超出适配器实现**：删除未实现的 `image-to-video` 声明，并增加运行时能力测试。
3. **热点来源 URL 可接受非 HTTP 协议**：上游链接现仅允许 `http` / `https`，拒绝 `javascript:`、`file:` 等协议；增加回归测试。
4. **候选素材公开编辑可伪造来源字段**：人工可调整排序与选择，但不能篡改 provider、素材 ID、媒体地址、作者和许可证字段；增加回归测试。
5. **工作流回执对象存在引用共享风险**：参数和实际模型 ID 在计划、授权与回执之间深复制，避免后续对象变更污染历史审计记录。
6. **免费资源统计可被未知 Provider 混入**：资源治理只统计明确许可的免费素材 Provider，其他来源进入待复核状态。
7. **客户端重试可能重复执行写操作**：创建、审批、节点编辑等写请求复用稳定的幂等键；服务端继续执行版本号与输入快照校验。
8. **空启动请求先在幂等摘要处异常**：`JSON.stringify(undefined)` 不再直接传给哈希函数；无效输入现在进入统一的用户输入校验，且不会调度生产。
9. **显式错误模型可能被全局默认值覆盖**：用户明确填写但不合法的模型现在直接拒绝，不再静默替换为全局默认模型。
10. **公开 DTO 与降级理由可能泄漏服务器路径**：公开运行详情递归脱敏系统绝对路径，参考分析与素材语义降级理由也执行同一边界；覆盖 `/Users`、`/home`、`/tmp`、`/workspace` 等路径。
11. **发布包携带内部 Artifact 字段**：发布包只写允许公开的描述字段，不再序列化 `uri`、内联 `data` 或内部备注；资源清单中的来源链接只接受无用户名密码的 HTTP(S) URL。
12. **参考视频只绑定上传编号和大小**：上传时计算 SHA-256，运行 Brief、节点输入版本和执行副本绑定同一摘要；分析前后均校验字节。旧运行可以查看，但重新执行参考分析前必须重新上传。
13. **零生成任务仍显示空的实际模型列表**：没有真实调用时省略 `actualModelIds`，避免把空数组误读为已执行模型证据。
14. **无效 JSON 被统一错误边界误报为 500**：Fastify 已识别的 `FST_ERR_CTP_INVALID_JSON_BODY` 现在返回中文 400，未知异常仍保持 500；新增服务端回归测试。
15. **外部模型“已配置”被写成“可用”**：按量 Provider 现在显示“已配置”，订阅 broker 显示“已连接”；不再把密钥、socket 或健康探测存在冒充为额度与真实调用成功。
16. **内部热点服务在线却提示未配置地址**：无可公开浏览器地址的健康内部服务现在标注“内部服务已连接”，只有停止状态才提示未配置地址；新增可访问性回归测试。
17. **导演可能交付空的生成提示词**：导演 Prompt Pack 升级为 `video-factory/director-v6`，逐镜生成提示词必须包含主体、动作、环境、镜头和时间节拍；结构化校验拒绝空字符串，避免把无效输入带到付费节点。
18. **供应商提交前拒绝仍被记为实付**：配置费率只在供应商受理任务并返回 `taskId` 后保守计入；未取得 `taskId` 的模型未开通、参数校验或供应商前置拒绝，实际成本记为 0。
19. **编排节点掩盖内部计费任务数**：执行凭证新增 `meteredAttemptCount` 与 `meteredFailedAttemptCount`，按取得 `taskId` 的外部任务统计，而不是把整个 AI 逐镜路由节点固定算作一次调用。
20. **计划模型被误写成实际使用模型**：`actualModelIds` 只收录已取得外部 `taskId` 的模型；未被供应商受理的模型仍保留在计划与错误证据中，但不进入实际模型清单。
21. **免费降级成功掩盖付费子任务失败**：即使素材节点通过免费卡片降级并整体成功，成本面板和节点证据仍分别展示已受理任务数、失败任务数、实际成本和待回填状态。
22. **供应商返回的未验证媒体 URL 提前进入审计文件**：外部 URL 只有在协议、地址、重定向、类型、大小和完整下载均通过后才写入成功任务；被拒绝的私网或异常 URL 不再持久化。
23. **全免费路由被成本面板误判为一次待回填调用**：AI 逐镜路由即使没有任何付费任务，也会显式返回 0 次计费、0 次失败和 0 元实际成本，不再触发旧回执的保守推断。

## 架构边界

- 模型解析优先级固定为：节点覆盖 > 本次任务覆盖 > 模板默认 > 全局默认 > Provider 默认。
- 模板保存声明式生产蓝图；任务启动后保存不可变快照，避免模板后改影响历史任务。
- 每个已启动节点保存输入版本和输出版本。人工修改形成新版本，后续节点标记为 stale，必须重新生成。
- 任何计费 Provider 执行前都生成 Spend Plan，冻结输入版本、Provider、模型、估算金额、成本上限和最大尝试次数。
- 前序输入、输出、Provider 或模型变化后，旧付费授权立即失效，必须重新确认。
- `actualCostCny` 在供应商任务已受理、但不返回账单时使用配置费率保守记账，并明确标记为 `configured_rate`，不冒充供应商实扣；提交前拒绝不计费。
- 参考视频原文件与候选素材私有清单不通过公共产物接口暴露；UI 只展示可审阅的制作语法和脱敏候选信息。
- 参考视频上传元数据、运行输入快照、私有副本和产物摘要使用同一 SHA-256 身份，防止审计后同尺寸替换。
