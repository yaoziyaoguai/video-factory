# PERF-R11-01：素材审查异常慢的根因调查

状态：**OPEN（根因已有证据，未做任何降低质量或思考强度的改动）**。用户要求：即使最终成功也必须查明，不能用降低模型、思考强度或删减必要质量证据来掩盖。

## 方法

扫描本工作区全部 `model_trace.json` / `agent_loop_trace.json`，抽取每次真实模型调用的 `providerWaitMs`、`reasoningTokens`、`completionTokens`、`promptTokens`、`firstOutputEventMs`、`modelAttemptCount`、`structuredRepairCount`、`modelId`，去重后得 **154 个样本**。原始统计见同目录 `perf-r11-01-stats.log`，脚本 `/tmp/vf-perf-stats.mjs`。

## 结论：耗时由推理 token 量决定，不是排队/重投/重复证据

| 相关量 | Pearson r（对 `providerWaitMs`） |
| --- | --- |
| `reasoningTokens`（全样本） | **0.913** |
| `reasoningTokens`（glm 子集，45 条） | **0.954** |
| `completionTokens` | 0.903 |
| `promptTokens` | **−0.186**（无关） |

耗时最长的 5 次与推理 token 最多的 5 次**是同一组、且顺序一致**：

| 推理 tokens | 等待 ms | 模型 | 尝试 | 结构修正 |
| --- | --- | --- | --- | --- |
| 36514 | 989138 | glm-5.3-flash | 1 | 0 |
| 34486 | 904635 | glm-5.3-flash | 1 | 0 |
| 27194 | 755687 | glm-5.3-flash | 1 | 0 |
| 21608 | 497252 | glm-5.3-flash | — | — |
| 20528 | 431850 | glm-5.3 | — | — |

glm 的推理生成速率中位数 **45.9 tok/s**（区间 21.7–77.8），全样本平均 36–50 tok/s。即：**等待时间 ≈ 推理 token 数 ÷ 稳定的生成速率**。

排除项（全部有数据）：

- **不是排队**：主片本次调用 `queueWaitMs = 1`。
- **不是重投/结构修正**：全 154 个样本中 `modelAttemptCount > 1` 的 **0** 个、`structuredRepairCount > 0` 的 **0** 个。主片三次慢调用都是单次尝试、零结构修正。
- **不是输入体量**：`promptTokens` 与耗时几乎不相关（r = −0.186）；最慢三次的 promptTokens 只有 24036 / 24199 / 33192，并非最大。
- **不是重复提交证据**：单次 produce 只提交一组证据帧；audit 是设计上的第二次独立审查（必须重复携带图片才能独立判断），attempt-7 全程 2 次调用（1 produce + 1 audit）合计 1117 秒。

## 为什么"这次特别慢"

本次素材审查是**整片预检**（5 场、24 帧、criteria 13–16 条跨场连续性核对），推理量 27194–36514 tokens，落在全样本分布的**最顶端**（语料常见量级 3.5k–21k，本次是常见的 1.5–10 倍）。因此"异常慢"的实质是**异常大的推理输出在正常速率下生成**，而不是链路异常。

## 可见性缺口（可改进但不得降质量）

`firstOutputEventMs === providerWaitMs` 在 44/153 条（即 glm 全部）成立：**宿主在整个等待期间收不到任何增量输出事件**，直到完成才有第一个事件。这正是"看起来卡住"的来源——宿主无法区分"正在生成"与"连接停滞"。这是可独立改进的**可观测性**问题，与质量合同无关。

## 风险

实测最长 989138 ms，占 Broker `timeoutMs = 1200000` 的 **82.4%**；主片本次 755687 ms 占 63%。余量已经很薄，一旦推理量再增或速率波动就会撞超时。

## 记录的建议（本轮不实施，因均涉及行为或阈值变更）

1. 让宿主在长等待期间拿到可观测的进度信号（心跳/阶段事件），不改质量合同。
2. 明确并复核 Broker 超时余量：已实测到 82.4%，当前阈值是否仍安全需要单独决策。
3. 复核整片预检 criteria 是否存在可合并的重复推导——任何改动必须保持同一质量合同与必要证据量，不得以降低核对强度换取速度。

## 边界

本节**没有**改动模型、思考强度、证据帧数、criteria 或超时阈值，也没有据此关闭 PERF-R11-01。
