# 本地素材来源配置

当前默认用于个人娱乐、非商业视频。许可禁止商用不等于不能个人使用；是否能剪辑、公开发布和是否要署名仍按具体条款判断。应用不会因这次接入新增“必须能商用”的制作门槛。

## 已有自动接入

| 来源 | 能交付 | 本机配置 | 额外要求 |
|---|---|---|---|
| Pexels | 图片、视频 | `PEXELS_API_KEY` | 遵守当前平台许可，图库画面不冒充新闻事件实证 |
| Pixabay | 图片、视频 | `PIXABAY_API_KEY` | 遵守平台缓存、下载与内容许可要求 |
| Unsplash | 图片 | `UNSPLASH_ACCESS_KEY` | 使用开发者应用 Access Key（不是 Secret Key）；初始请求额度有限，正式额度需申请 |
| Coverr | 视频 | `COVERR_API_KEY` | Demo 免费额度每小时 50 次；采用正式下载链接并保留 Coverr 来源 |
| Wikimedia Commons | 图片、视频 | 不需要 Key | 至少短边 720px；图片不超过 64MB/8000万像素、视频不超过 128MB；逐文件保留作者及许可，媒体域名需可访问 |
| The Met | 图片 | 不需要 Key | 只采用明确开放的馆藏图像；CC0；下载后检测真实尺寸 |
| Cleveland Museum of Art | 图片 | 不需要 Key | 中国与世界艺术馆藏；逐条 CC0、官方 print 高清 JPEG；真实下载和静音素材入片已通过 |
| Internet Archive | 视频 | 不需要 Key | 仅 stock_footage 集合的明确开放许可 MP4/WebM；至少 720p、128MB 内；真实检索通过，当前本机正式下载受 DNS/代理路径阻断 |
| NASA | 图片、视频 | 不需要 Key | 科学/航天题材；保留机构与作者，核对第三方权利；下载后检测真实尺寸和时长 |
| Openverse | 图片 | 不需要 Key | 聚合来源，保留原站与具体许可；允许符合条件的非商业许可，不采用禁止改编内容 |

将变量交给**本地 Studio 启动进程**后重启服务，在“创作设置 → 画面来源”查看连接配置状态。不要把密钥写入前端、文档、截图或提交；页面“已配置”不表示真实网络和账号额度已验证。

Unsplash 官方申请入口：https://unsplash.com/developers 。接口与指南：https://unsplash.com/documentation 。

Coverr 免费 Key 入口：https://coverr.co/developers 。接口文档：https://api.coverr.co/docs/ 。当前只接入原生图库视频，不把其 AI 生成内容混入“实拍素材”。使用 API 时按官方要求展示 Coverr 来源；正式签名下载链接只保留在私有候选清单，不写入公开产物。

2026-09-20 接入补充：

- Coverr 每次搜索最多两页，每页最多 50 条，过滤 AI/付费项后补齐候选；并不保证返回指定数量。没有实现服务端竖屏筛选，界面改为“横竖屏候选”。
- Coverr 鉴权搜索禁止跳转。公开预览优先使用不含查询签名的 thumbnail/poster；两者都不可安全公开时显示无缩略图，不伪造可访问地址。候选、采用素材、素材库及授权待办均展示可点击的官方 logo。
- Pixabay 响应按完整请求（含账号、媒体类型、查询和数量）隔离缓存 24 小时；默认目录是 `~/.cache/videofactory/stock/pixabay`，遵循 `XDG_CACHE_HOME`。跨进程文件锁合并同一查询；失败不缓存，缓存文件名只含摘要。没有新增 Redis 或数据库服务。
- Wikimedia 最初只接视频，2026-09-21 扩展图片：有界两页检索，保留至少 720p 的合适转码，不为凑体积降到 240p。CC BY 需署名、许可链接和修改说明；CC BY-SA 还须按同许可分享改编作品。条件在候选、工作区及素材库显示，不新增商用门槛或购买流程。
- 缺作者/许可、待审/争议标记、未知多重许可及超体积/低清视频不会自动采用。Commons 元数据不是版权担保；发布前仍应核对文件页与第三方权利。

Unsplash 接入行为：

- 搜索只请求图片，不以静态图冒充视频；搜索失败会保留错误，不转为收费生成。
- 预览使用官方 CDN URL，保留摄影师和 Unsplash 链接。
- 只有采用图片才上报下载事件，搜索/预览不会上报。上报失败不跳过、不自动反复上报。
- 正式图片保存在本地用于渲染，来源、作者、许可和内容 SHA 随现有产物链保存。API key 与下载跟踪 URL 不进入公开候选、产物清单或发布包。
- 沿用原下载大小、时限和网络地址保护；不会为了新源降低画面审查质量或放宽付费边界。
- 跨作品另一次使用是否需要再次上报，应随该使用动作遵循官方指南；当前未新增独立的“从素材库插入新作品”采购/导入流程。

## 国内与付费素材

摄图网、站酷海洛是项目此前记录的正式图片/视频 API 合作候选，但现在**尚未自动采购接入**。2026-09-20 再核查时官方入口分别返回 403、418，最新申请资格和接口合同尚未复证。需要用户后续确认：

1. 正式 API 合作权限（不只是普通网站会员）；
2. 授权对象是个人还是企业，以及个人视频/公开发布的使用范围；
3. 搜索、下载的收费或套餐配额、重复下载规则；
4. 正式与测试凭据、授权书获取方式。

不要提前填写项目还不消费的虚构环境变量，不把网页会员 Cookie 当作 API key。未知价格不能假设为免费，购买结果未知不能自动重买。现有本地用户授权流程保持不变。

官方接口资料：[摄图网](https://699pic.com/vip/apiDoc)、[海洛开放平台](https://open.hellorf.com/)。国内非商用学习资源也在候选范围内；缺少正式 API 时不通过抓取绕过平台下载限制。

## 验证状态

离线合同测试、真实账号搜索、正式下载和成片验证分开记录。前序工作已记录 Pexels、Pixabay、Unsplash、Coverr 的配置与真实搜索；2026-09-20 本轮调研没有重新读取密钥或执行认证下载，不能据此宣称完整成片验收。国内合作库仍未接入。

最新官方资料与后续接入顺序见 [素材库扩充调研与接入建议](stock-source-research-20260920.md)，实施与验证结果见 [本轮接入验收](stock-source-implementation-20260920.md)。Wikimedia 已注册为 `wikimedia-stock-v1`，真实查询返回两条上海场景候选；但本机访问 `upload.wikimedia.org` 超时，正式下载未通过，ffprobe/解码尚未执行，不能宣称已完成真实入片验证。Freepik/Magnific 尚待账号权益和凭据验证。

### 2026-09-21 增量验证

Met 与 NASA 图片已分别通过正式 Python worker 下载、解码、1080×1920 静音样片渲染。不是全产品 E2E 或 TTS 验收。

Wikimedia 已支持已有 HTTP CONNECT 代理，但当前代理到本机解析的目标 IP 在 TLS 握手阶段超时；没有绕过目标 IP 检查。Openverse 搜索在本机网络超时，不能标记为真实可用。NASA 视频此前受 12MB 下载上限限制；用户确认后本地图库视频统一提高到 128MB，但 NASA 视频尚未因此重新通过真实入片验证。

大图处理已补齐：静态图片单独采用 64MB 下载、8000万像素校验上限，原有网络安全/时限不变。保留原文件与来源许可；渲染前按实际输出宽高计算等比例缩放，给裁剪和镜头轻微运动留 1.5 倍余量，不放大小图。衍生图使用 PNG，处理记录含原图 SHA-256、原始/输出尺寸，并写入渲染清单。缩小分辨率不是数学上无损，但 PNG 不再额外引入有损编码；保留原件意味着总磁盘占用不一定减少。CMYK 等不适合直接转换的模式继续使用原图。

真实 NASA 17.2MB、8000×8000 大图已完成下载、解码与 1080×1920 样片渲染；渲染副本为 2880×2880、约 9.92MB。无需新 API Key 或付费。

新增源查询与详情共享 30 秒预算（每次网络等待最多 10 秒、不重试失败请求；底层系统 DNS 不提供硬中断保证）。导演明确查询优先，最多尝试原查询与两条已有搜索词；不暗改成固定题材。重复原站 URL 在同镜头候选中去重，未知尺寸显示“待下载后核验”。

完整范围、失败证据、未完成项见 [2026-09-21 实施与验证记录](stock-source-implementation-20260921.md)。

### 继续扩充的实际顺序（2026-09-21）

- **已新增 Cleveland**：设置目录、导演来源、免费路由、Python worker、来源/署名展示均接线；API 单次有界检索，不取 TIFF 或低清 web 缩略图。无需配置账号。中国馆藏样本 2302×3400、3.30MB，下载/解码/1080×1920 静音样片通过。
- **Internet Archive 已实现**：`archive-stock-v1`，从 stock_footage 集合逐项核对 CC0/PDM/CC BY/BY-SA/BY-NC/BY-NC-SA；不自动接受旧 publicdomain URL、ND、不明许可、私有内容或低清版。检索/详情共享 30 秒、最多 6 项详情、不重试失败元数据请求。优先高分辨率，同分辨率选择较小的合格文件。128MB 是单个文件上限，不是分辨率目标，也不提高超时。下载后 ffprobe 核验真实尺寸和时长。
- **Archive 本机尚不可算真实入片通过**：1920×1080、32.4MB 的 CumulusClouds 已找到；正式下载两次有界尝试后在代理隧道超时（23.253 秒结束），未完成解码/渲染。普通域名代理请求同文件返回 206、读取 1KB 成功，但它不是正式安全下载路径，不能据此算通过。没有关闭 IP 固定、TLS 或 SSRF 校验；未自动重试整条 QA。
- **Art Institute of Chicago 暂缓**：无 Key API 可访问，但本机官方 IIIF 图片返回 HTTP 403；未添加不可下载的空壳来源，不绕过限制。
- **Flickr**：公开摄影图片适配器及正式 worker/目录/导演/署名已接线，需要 `FLICKR_API_KEY`。只采用逐项明确许可且可下载的公开图片，采用前再次核验；未配置时不进入导演可用来源。真实鉴权/下载尚未验证。
- **Europeana**：后续正式 API 候选，需要开发者 Key/权限，目前未实现。
- **Vecteezy、Magnific**：需核实 API 权益、价格及使用/缓存条款；Vecteezy 本轮文档访问 403，不能依据猜测开发。
- **国内海洛、摄图网、视觉中国、光厂**：优先核实 API 合作与下载授权，不把网页会员等同 API 权限。尚未自动接入；在可取得正式接口和授权前使用现有人工素材导入，不抓取受限下载。

官方依据：[Cleveland API](https://openaccess-api.clevelandart.org/)、[Cleveland Open Access](https://www.clevelandart.org/open-access)、[Archive 元数据 API](https://archive.org/developers/md-read.html)、[Archive 自动访问约定](https://archive.org/developers/bots.html)、[Chicago API](https://api.artic.edu/docs/)。
