# 模型与声音审片配置

## 模型库与角色默认

在“创作设置”先配置模型，再选择角色默认。模型库按文本生成、图片 / 视频 / 语音生成、图像 / 视频 / 音频理解区分能力；同一接入可以具备多种能力，也可以被多个角色使用。

角色不绑定供应商。节点的明确选择优先于本条视频的选择，再优先于角色默认；全局变更不改写已经创建的制作，也不把旧请求转换成新生成。

## 添加模型

文本模型支持 OpenAI Chat Completions 和 Anthropic Messages 两种接入协议。填写实际的上游模型 ID、HTTPS 地址、密钥、输出上限和服务支持的参数。

这两种协议不通用；OpenAI Responses 也不能当作 Chat Completions 地址使用。自配模型不自动继承其他供应商的专有参数。保存和读取配置本身不调用付费模型，“已配置”不代表兼容性或账号额度已验证。

图片、视频和配音仍使用已适配的供应商协议。只添加一个文本兼容地址，不会获得新的媒体生成接口。常用密钥变量见 README 和[素材来源配置](stock-sources.md)。

新增接入支持停用与重新启用；停用不删除历史请求，原请求仍按原身份查询。需要更换密钥或地址时，新增接入并停用旧接入，避免混淆旧请求。

## 配置安全

配置通过已有登录和 CSRF 边界进入宿主模型服务。密钥不会回显到浏览器、制作记录或日志；私有配置不进入 Git。

接入地址须为 HTTPS，不包含明文 IP、localhost、URL 凭据或查询参数；鉴权请求不跟随跨域重定向。这些校验面向受信任的个人管理员，不代表支持不受信任用户任意填写地址，也不等于完整的 DNS 重绑定防护。

## 声音审片

声音审片在成片复核阶段读取实际成片音轨，并结合脚本与带时间码的画面提供独立意见。声音报告绑定实际音轨和成片版本；它不等同于生成后、渲染前的人工试听确认。

必须使用支持音频与图像输入的接入。当前 OpenAI 协议适配器可以发送 `input_audio`；Anthropic 适配器不提供直接音频输入。超过当前 5 MiB 音频输入上限、缺少音轨或缺少可用模型时，会明确显示未审听，不截断后冒充完整审听。

转写不代表听过声音，画面抽帧也不能证明逐帧口型同步。模型意见由你判断；缺配置、失败、未知结果和未审听分开呈现，不伪造通过或零费用。

## 当前限制

模型管理要求配套宿主模型服务已启动。更换版本时要同步部署 Studio 与模型服务，并检查服务身份。

配音时间调整只复用原声，不改善原声韵律或发音；真实声音审片的效果也取决于模型能力。本地合同与恢复测试通过，不代表每个新接入都已获得真实服务验收。
