## B 从哪个入口开始

| 入口 | 你提供什么 | 下一步 |
| --- | --- | --- |
| 热点 | 一条线索或新闻来源 | 核对来源，采用选题 |
| 系列 | 一个栏目和本集目标 | 保存系列，按需生成路线图 |
| 自有想法 | 自己想讲的一件事 | 保存想法，准备简报 |
| 案例 / 脚本 | 参考内容与修改方向 | 准备简报，明确借鉴范围 |

选题采用或系列保存后，仍需新建制作。
在新建制作中点击“开始前期构思”，才启动制作。
系统先核对简报，确认后再进入构思。

## C 一条视频怎么完成 {span=2}

```flow TB
内容简报 -> 构思: 确认内容简报
构思 -> 脚本与时长: 采用构思
脚本与时长 -> 导演方案与画面来源: 采用脚本
导演方案与画面来源 -> 素材与声音: 核对方案及报价
素材与声音 -> 渲染与审片: 确认素材与声音
渲染与审片 -> 人工终审与发布文案: 采用当前成片
人工终审与发布文案 -> 下载交付: 分别确认
脚本与时长 --> 构思: 需要修改上游时返工
```

图中合并了部分步骤。素材、声音、审片、终审和文案仍分别确认。
试听声音后，确认才会进入渲染。
采用制作中的阶段结果会继续下游，可能调用下一阶段模型。
脚本阶段先确认建议总长和各镜安排。
明确设置的时长范围发生冲突时，可改内容或调整范围。

## D 哪些操作会调用模型 {span=2}

| 操作 | 保存或执行什么 | 调用后果 |
| --- | --- | --- |
| 保存想法、创建系列 | 保存内容或规则草稿 | 不启动制作 |
| 生成并审计路线图 | 生成系列候选和审计意见 | 调用模型 |
| 开始前期构思 | 启动简报检查与制作 | 调用已配置的生成能力 |
| 采用构思或脚本 | 确认本阶段，继续下游 | 可能调用下一阶段模型 |
| 确认付费素材报价 | 授权对应采购 | 执行付费请求 |
| 只调整配音时间 | 移动已核验的原声与留白 | 不重新配音或采购画面 |
| 人工终审定版 | 准备发布文案和发布包 | 可能调用文案模型 |
| 采用已有发布文案 | 确认发布包中的文案 | 不再次调用模型，不对外上传 |

独立配音按配置计费，不逐笔弹素材报价。
免费图库仍有许可和署名条件。
费用页中的 token、估价和已记录金额不等于实付账单。
缺失用量或未核账时，费用仍待核。

## E 失败后先找已有成果 {span=2}

### 系列候选

```flow TB
原请求状态待核 -> 原请求查询: 不重新生成
原请求查询 -> 系列候选: 候选已生成且格式有效
系列候选 -> 待采用草稿: 当前版本允许时取回
```

系列“取回”像把待确认的草稿拿回编辑区。
取回不会自动采用，也不会再生成或审计。
缺原始版本的旧候选只能查看。
当前稿已变化时，旧候选不能覆盖当前稿。
已保存的有效系列候选可直接查看。

### 制作中的失败节点

```flow TB
制作已失败 -> 原请求查询: 核对原任务
原请求查询 -> 制作原结果: 原请求已核验成功
制作原结果 -> 后续未完成步骤: 取回结果并继续
```

制作中的“取回结果并继续”有不同后果。
它不重复原生成，但可能执行后续审计或阶段。
结果仍不确定时，只查询原请求，不重新发送生成请求。

```callout warn 有成果才能确认
可选审计失败不取消采用有效成果的权利。缺文件、格式无效或身份冲突时，先修正对应问题。
```

## F 画面来源和声音来源分别选 {span=2}

画面可按当前接入能力使用图库或 AI 生成。
独立配音并不要求画面来自图库。
在新建制作的“02 画面与声音”查看画面来源策略。
需要 AI 画面时，选择“允许 AI 生成画面，按实际镜头报价”。

| 声音来源 | 画面与声音怎样制作 | 可以调整什么 |
| --- | --- | --- |
| 独立配音 | 画面与配音分开制作 | 分段、留白；生成后复用原声调时间 |
| 模型原生音画（试用） | 同一视频模型逐镜生成画面和声音 | 生成前描述声音意图；生成后试听原片 |

原生模式不混用图库或图片，不另买独立配音。
它没有独立音色选择、配音调时或同步字幕。
对白、口型和跨镜人物一致性须查看实际样片。
切换声音来源要创建关联返工，旧成果仍保留。

## G 交付前检查什么

1. 看、听实际成片，核对当前版本。
2. 区分机器审片与独立人工终审。
3. 确认发布标题和正文。
4. 核对素材许可、署名和费用待核项。
5. 下载成片和发布包，自行上传外部平台。

只改发布文案，不重复对同一成片逐条表态。
更换媒体或审片证据后，需要重新终审。
当前不提供独立背景音乐、环境音或拟音混轨。
模型已配置，不代表账号额度或真实效果已验证。
