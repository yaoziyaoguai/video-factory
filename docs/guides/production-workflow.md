# 制作流程与声音调整

## 选择入口

- **热点**：从选题和来源证据开始。正文无法读取时会标明，标题不能代替已核实的事实。
- **系列**：从栏目与剧集计划开始，保留系列规则和前后集关系。
- **自有想法**：填写内容目标、受众、时长意向和画面要求。
- **案例 / 脚本**：选择参考内容，说明借鉴要求和自己的创作意图。

四个入口随后使用共同的制作流程。新制作的目标时长仅作参考，模型会在脚本中提出具体的总长与逐镜安排。

需要明确时长时，勾选“必须在此范围内”，可只填写最短或最长一端。不设范围时，由你在脚本阶段决定采用的时长。已有旧版制作继续显示原时长约束。

创建时可选“解说视频”或“角色剧情”。角色剧情先由 AI 提出人物和台词，再由你编辑、采用；不要求先填完整角色表。声音来源默认是独立配音，也可主动选择“模型原生音画”。系列模式保留本集上下文，不自动保证跨集人物外观一致。

选题阶段的创作建议可以沿用，也可以在新建时取消沿用；已有内容简报可编辑或清空这些建议。系列路线图不是外部参考来源，不会作为平台热度或已核实事实展示。前集定版后，核对最新交接与本集计划即可决定是否采用下一集，重新审计是可选操作。

## 选择声音来源

- **独立配音**：画面与声音分别制作。角色剧情可选各角色的系统音色，不包含口型同步、声音克隆或多人抢话混音；下文的分段、留白与配音时间调整适用于此模式。
- **模型原生音画（试用）**：固定一个视频模型，逐镜一起生成画面和声音。可用于解说或多角色剧情，不混用图库或图片，不另买 TTS。角色声音要求、台词和停顿作为创作意图交给模型，实际表达与口型以原片为准。没有可靠同步时间码时明确不提供同步字幕，不用猜测时间生成字幕。

制作创建后不原地切换声音来源。需要切换时用“基于这版重新制作”创建关联返工，保留旧成果；新制作按当前来源重新核价，不能沿用旧费用批准。

原生模式在素材采用后本地准备声音，随后等待你试听。它没有独立音色选择、分段与留白、只调整配音时间等 TTS 操作。准备失败时先查看已保留的源片，再选择本地重试或返工；不会因为声音处理失败就重新购买视频。若要修改已经生成的原声台词，须回到创作流程返工，重新生成可能产生费用。

## 构思、脚本与导演方案

构思、脚本和导演方案按顺序处理上游已确认的信息。文字初稿附一轮审计，页面同时展示稿件和内容建议。

脚本确认区显示建议成片时长、镜头数量与各镜安排，支持 1–24 镜。采用脚本前不会生成下游导演方案、采购素材或制作配音。若稿件超出你明确设置的范围，可修改稿件，或修改、取消时长承诺；完整提案和旧稿都会保留。

导演或声音安排后来改变了成片时长时，页面会显示原方案与新方案的差异，由你在对应步骤确认。素材原片比实际使用的片段更长，不等于成片变长；具体单镜仍受所选模型和已有媒体覆盖能力限制。

你可以直接确认，也可以多选建议、补充自己的要求后提交修改。修改后先看新稿；系统不会自行循环“改稿再审”。需要再审时主动选择审计当前版本。

质量意见不替你作决定。未复核或有风险的版本会说明后果，由你选择是否采用。确认后仍可查看历史产物；修改上游会使相关下游版本过期，需要重新确认。

角色剧情可在脚本中增删角色、分配台词；独立配音模式还可选择系统音色。删除仍有台词或出场引用的角色前，先处理这些引用。独立配音的角色暂未选音色可以保存，但配音前必须选好；原生模式只填写声音要求，不选择 TTS 音色。脚本采用后仍可通过“修改角色与台词”返回当前制作修改。原声音和画面保留，实际需要重新生成的部分由修改内容决定。

## 素材与费用

在选材和执行方案中核对每个镜头的来源。免费图库也有署名、剪辑和公开发布条件；“免费”不代表不受许可约束。

付费图片和视频在调用前报价并请求确认。配音按已配置的服务自动计费，不逐笔弹素材报价。界面估价和已记录费用不是服务商实付账单。

来源失败时先查看错误与已保留的结果，再选择重试或修改来源。请求结果不确定时先查询原请求，不反复点击生成。

## 生成前：分段与留白

在素材确认前打开“分段与留白”，查看当前脚本与画面来源。使用 v2 计划时可编辑文字分组、时间窗口和显式留白；旧 v1 计划保留整组编排能力，不会被悄悄升级。

角色剧情按每句台词显示角色、音色、时间窗口和费用，不把不同角色合并成连续旁白。可调整窗口与留白；改台词或音色需返回角色脚本。音色意图与表演说明是创作要求，不代表当前配音服务已实现逐句情绪控制。

编辑后先核对候选计划和价格状态，再保存。价格未知时页面会说明，需要知情保存；不能把未知金额理解成免费。保存只更新计划，不确认素材、不生成配音，也不继续下一步。

上游内容变化后，旧计划只读展示，不能覆盖新来源。未保存稿件与已保存计划分开处理；关闭、重读或放弃时留意提示。

## 生成后：只调整配音时间

先试听原声或已生成的声音，再打开“只调整配音时间”。这项操作可以改变整组原声的位置和留白，不能改词、换音色、改变语速或修正原声发音。

没有保留分组原声与来源清单的声音，无法仅调整时间；未使用高级声音计划的制作也可能属于这种情况。页面会提前说明，原声音仍可试听和采用。当前不提供独立背景音乐、环境音或拟音混轨，审片中的此类建议需要外部后期处理，不能直接在本系统内执行。

首次生成发现原声放不进窗口时，已物化的原声、来源清单和费用记录会保留。没有成功合成整轨时不会假称配音完成；可通过时间调整解决冲突，或返回创作步骤修改。

本地调整复用原声，不调用新的配音服务，也不重新采购画面。成功后回到新声音试听确认；已有下游渲染和审片会过期，不能直接沿用旧确认。若音轨没有可用的同步字幕，会说明情况，由你决定是否采用无同步字幕版。

处理中的请求或未知响应按原请求身份核对，不新建请求重复调整。失败后可以保留输入、继续核对或明确放弃尚未采用的调整；放弃不等于回退已成功采用的声音。

## 渲染、审片与交付

确认声音后才进入渲染。技术检查核对媒体和时间线，模型审片提供内容意见，最终由你看、听并确认。未审听、未复核与审片失败会分开说明，不伪造通过结论。

已有有效稿件或成片时，可选审计异常不会取消你的采用权。失败页的恢复操作只整理已保存成果，不代表采用，也不重复生成或审片。进入人工审看后先明确采用，再到独立人工终审；终审后仍需确认发布文案。原审计结果和费用可能继续待核，可查询原请求，不能把采用理解为机器通过或账单结清。缺必需文件、结构或成果身份不一致时，先修正对应问题，已有进度保留。

发布确认区显示当前标题和正文。只修改文案时，不重复对同一成片逐条表态；更换媒体或改变审片证据后，重新完成独立终审。报告原文可展开查看，未审计、结果待核和风险说明始终可见。

已完成制作的 AI 文案修订和审计会先请你确认。AI 新稿保存后单独等待采用，不重新采购素材、配音或渲染。手工编辑的未保存文案暂存在当前标签；刷新后可从“编辑交付”找回。另一标签保存了新版本时，旧草稿仍保留，但不能覆盖新稿；先复制需要的文字，明确放弃旧草稿后，再基于当前版本编辑。浏览器暂存不可用时会提示先自行复制。

修改后需要重新确认受影响的步骤；未变化的上游与可复用素材按版本记录保留。最终下载成片与发布包，再自行上传到外部平台。

试用时请优先反馈不能继续、错误恢复、重复消费和产物不匹配的问题。自然韵律、内容质量和节奏需要结合真实输出判断，本地受控验证不能替代实际听看。
