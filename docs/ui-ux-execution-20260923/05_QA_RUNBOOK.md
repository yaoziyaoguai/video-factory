# 实现后的真实本地 UI QA

目标：验证改造后的易用性、视觉、响应式、动效与前端业务保护。**不是重新制作一条视频，不继承旧30/50元预算。** QA发生在实施/确定性测试通过后；作者本轮只交资料，没有执行这份实施后手册。

## Q0：准备与安全边界

1. 使用当前环境提供的QA/浏览器技能，先完整读取其说明。技能如含自动付费/部署/提交等步骤，本包范围优先。不要假设之前agent的浏览器会话仍活着。
2. 先记录git与环境，确认Node/包管理、构建时间/实际服务PID/工作目录/端口；不要打开`.env`、导出cookies/密钥或打印完整进程环境。
3. 本次取证曾使用Studio4320/API4321；Vite脚本默认端口不同。先只读确认，不能随便杀占端口进程或另起一套不知版本的服务。
4. 浏览器用本地地址；网络代理需本机回环绕过时，仅设置进程级 `NO_PROXY=127.0.0.1,localhost` 与小写等价，不改全局代理。真实云站不在本次QA范围。
5. 若现有服务有活动制作任务，**不重启、不生成、不批准**。如需启动真实本地服务，先确认启动不会自动恢复现有活动队列；无法排除就请求最小权限。可先继续组件/构建验证，不接fake broker。
6. 从当前repo文档和脚本选择启动方式，运行真实已有服务配置但不读取/打印密钥；确认新前端确实加载，而不是只看到旧服务health正常。
7. 证据放 `docs/ui-ux-execution-20260923/qa/<时间戳>/`，截图/录屏/日志仅本地保存，可能含作品内容，未授权不上传公共仓库。不要改审计输入截图。

### 允许的真实动作

只读导航、滚动、播放已存在的本地/已可访问免费素材与成片、展开报告、切页签/filter、打开未提交表单、键盘/尺寸/动效检查。新建表单用临时测试文字检查误关，**不点最终开始**。讨论不发送、不保存真实人工版本、不确认或回退阶段；真实模型接入/默认不保存、不启停、不探测。

**即便按钮看起来“不花钱”，调用模型、修改既有run、取回并继续、重试、暂停/终止、确认报价均不在本包授权。** 这些用确定性组件测试，真实缺口标NOT_VERIFIED。

不刷新热点冷收件箱/生成候选，不运行 `npm run test:e2e`，不启用 `VIDEO_FACTORY_E2E=1`。图片/视频/声音展示读取不等于生成许可。遇未经预期的业务写请求，停止该路径，记录脱敏method/path/时间，查原因，不能继续点。

## Q1：确定性回归与证据分层

执行03中的集中 `npm test` 与 `git diff --check`，保存完整输出、开始结束时间、退出码。测试中API/Broker使用既有依赖注入或mock；不要向真实服务投递夹具。

对费用未知、原任务迟到、过期确认、权限撤销、storage失败、新成片到达等不便安全制造的状态，用现有组件测试夹具。测试不是产品另一条fake生产链。

若录组件演示，画面/文件名标 `COMPONENT — 模拟状态，仅验证界面`；不把它放在真实E2E成片目录。没有组件浏览器入口时不为截图新建服务端测试路由：交UNIT证据、真实视觉标NOT_VERIFIED即可。

## Q3：交互与边界

1. **人工确认**：只读定位与取消真实弹窗可做，但若打开入口本身即发命令则不点。所有“0次confirm、只发一次正确body”由UNIT证据证明；QA报告注明没有真实放行。
2. **误关**：未提交表单输入临时中文和换行；四关闭入口分别测试返回。最后放弃清理；不上传真实参考视频。上传cleanup用mock证明。
3. **折叠**：填标题/角度/受众、改时长，再折叠与展开；输入仍可见。真实payload一致性用UNIT验证，不能为了观察body向真实服务提交。
4. **费用**：查看首部及页尾；没有此配置的真实状态用UNIT。未知金额不等于0；当前截图里的历史费用不是本轮消费。
5. **复核**：对照当前产物、结论、原文；所有真实意见能展开，风险入口存在且不替用户选择。source_assets与rendered_video不合并。
6. **焦点**：Tab/Shift+Tab遍历、Esc关闭与回焦；折叠区不接焦点；深链定位有可见焦点；打开modal背景不能收到Tab；新消息/轮询不能抢焦点。
7. **长文**：UNIT/组件用长中文标题、长URL、20条意见、空数据/错误、发送中；不把这些写到真实run。真实表单可用临时文字验证换行。
8. **来源**：免费素材仍检查署名与许可展示；只读打开源链接可以，不做下载许可未知媒体或重新购买。

## Q4：视觉、手机、动效

### 尺寸与键盘

三主尺寸必须；另检查320×700、375×812、1920×1080、桌面200%缩放。记录document.scrollWidth与clientWidth（允许≤1px舍入误差），检查按钮/费用说明是否被裁切，不能用body overflow-x:hidden掩盖问题。

手机仿真不是手机实测。若无真实iOS/Android浏览器，虚拟键盘、safe-area与系统字体缩放分别标NOT_VERIFIED。可做短viewport辅助测试但不能改名成真机测试。

焦点outline、文字/背景对比用实际computed颜色测；rgba先合成背景。白底token合格不代表叠在图片/disabled opacity也合格。需要信息不得仅靠色彩。

### 录像清单

- `motion-navigation-normal`：导航/设置分区/展开，普通模式。
- `motion-discussion-normal`：切页签、定位确认、输入不丢；不发真实讨论。
- `motion-assets-normal`：主动预览、切filter、暂停另一个媒体；无自动声音。
- `motion-reduced`：同样路径，reduce仍可操作且没有位移/揭幕。
- `component-stage-and-film-arrival`：若可做组件演示，覆盖M2/M6+同身份重复、换run；醒目标模拟。真实新增成片到达未经授权标NOT_VERIFIED。

用浏览器已有录屏/trace能力；如果技能不支持录像，明确缺口，不用连续截图假称录像。给每段起止状态、触发操作、时长、版本、证据类型。

按AC-16记录Performance：至少三次相同行为、设备/浏览器/构建模式、CPU是否限速、长任务与layout-shift、即时反馈；dev与生产构建不能混比。发现重复animation/listener先修原因，不仅减少时长遮掩。

## Q5：日志、费用、重试纪律

- Console收集warning/error及触发页；Network仅记录脱敏method/path/status/计时，不保存完整认证头、API key、cookie或含敏感字段的HAR。
- 若真实浏览器动作失败，先记时间、runId、截图、错误、相关只读日志；有新依据才重试一次。同一错误不得连续点击，特别是付费结果未知。
- 本包目标是**新增付费/生成动作0次**，用动作清单与Network/已有可见调用记录对照；未核账单不能写“供应商已确认¥0”。报告可写“本轮未主动发起模型/媒体任务；账单未独立核验”。若发现后台新调用，记录并停相应路径。
- 本地环境阻塞时继续其他独立可测项；不自动改密钥、重置数据库、切fake或扩预算。

## Q6：集中修复与收尾

只修本包范围内的UI问题，一次归类后集中改、重跑影响测试和截图；最终再跑集中回归。范围外问题写根因线索、影响、最小下一步，不把本轮变成工作流重建。

RESULT包含：全部验收状态、真实/组件证据索引、前后截图、motion录像、测试exit、服务实际版本、费用/动作记录、剩余风险。没有视频生产新E2E就明确写“本轮未重新验证生产全链路”。交付后停止，不commit/push/deploy，不继续操作真实run。
