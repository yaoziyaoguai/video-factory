1. 不把原费用政策改成“每个付费动作都必弹窗”；文案按范围表达，免费画面不扩大为视频免费。

4. storage读取未决命令失败也不能当“没有命令”换新身份；服务器成功仅本地清理失败不能报成提交失败。

6. 新增动效以产物/稿件身份而非高频run.revision驱动；不remount播放器/输入。
7. 本地UI QA不沿用历史预算，不为缺少真实状态制造业务写或付费任务；可用组件证据，但必须明标。
