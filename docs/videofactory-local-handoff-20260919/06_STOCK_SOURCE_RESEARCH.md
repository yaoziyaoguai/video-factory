# 国内外素材来源调研与接入边界

调研日期：2026-09-19–20。依据公开官方页面，不登录、不使用用户密钥、不采购。范围只限图片与视频素材，不扩展音乐、字体或新生产工作流。

用户用途确认（2026-09-20）：默认个人娱乐、非商业创作。允许个人非商业使用的素材也纳入候选，不因“禁止商用”一票否决。另行区分是否允许剪辑、公开发布、署名和自动下载；仅限学习交流不能擅自推断为允许公开传播。付费 API 的“商务开通”只是供应商准入要求，不要求用户的视频改为商用。

## 结论

当前自动生产已实现 Pexels、Pixabay，以及本轮新增的 **Unsplash 图片**。Unsplash 已接通搜索、下载事件、物化、产物来源、素材库和预览署名，离线合同测试通过；真实账号鉴权与搜索下载尚未验证。下面列出的国内供应商**尚未接入**。用户已授权扩充素材来源，原 `05_BACKLOG.md` 的“本轮不实现”不再作为当前范围限制。

国内优先候选为摄图网和站酷海洛：两者有正式开放平台，不通过网页抓取绕过授权。摄图文档已完整阅读；海洛明确提供不产生真实购买的测试应用，适合开通后先验证采购链。选择哪家仍取决于个人账户准入、素材覆盖和套餐费用，不能凭营销数量决定。不能把官网链接、预览结果或配置项称为生产接入。

## 摄图网已核实的接口合同

- `POST /v2_0/general/search`：gid、model（1 图片 / 2 视频）、kw、page、size、秒级 time；时间戳有效期 60 秒。图片/视频筛选不相同，视频模板不能当实拍片段。
- `POST /v2_0/general/detail`：mid、model、gid、time；视频详情有 duration、尺寸与可用分辨率。
- 签名：按参数键排序，原始键值以 `&` 连接，末尾拼 token 后取 MD5；不能凭空换成 HMAC，也不能把 token 写进日志/前端。
- `POST /v2_0/general/download`：mid、model、gid、time、user_type；企业需 name，实拍/背景视频需 rate。接口返回正式 URL 与下载记录 did；文档某个 JSON 示例漏 did，所以没有 did 时不能伪造授权证据。
- `POST /v2_0/general/stat`：按时间区间获取下载记录；这不是按本地 operationId 查询的幂等合同。
- `GET /v2_0/general/license`：以 did 获取授权协议二进制。应与素材 ID、内容 SHA、授权主体绑定保存。
- `1009` 签名失败，`1010` 每日请求超限，`2003/2004` 接口/参数无权限。错误不能被当成“搜索无结果”。
- 文档示例使用 HTTP；公开分类接口的 HTTPS 已通，但正式鉴权接口仍须通过试用核实，凭据不得降级走明文 HTTP。

### 不能擅自补的合同

公开文档没有可供本项目使用的统一单价、余额/配额预检或按客户端操作 ID 幂等购买接口。接口接入不只是“填一个 key”。需要供应商确认：搜索是否计费、下载何时扣额度、重复下载是否重复计费、个人/企业授权范围、授权证明获取方式。

沿用现有付费安全原则：用户批准具体报价才可采购；结果未知时停止购买并保留原操作，不自动再买。图库采购必须是 `stock_image/stock_video`，不能借用生成模型接口写成 `AI-generated`。带水印预览绝不进入成片。

图片和视频文档均能公开访问。本轮已核实接口入口、准入和测试环境说明，未声称已完整核对所有响应字段：

- 正式应用与测试应用分别发放凭据；官方明确测试应用的购买不真实提交、不会实际付款。

- 预览链接可能带水印且约 10 分钟过期，不可当作长期正式素材地址。
