# 扩充图片与视频素材来源

范围更新（2026-09-19–20）：用户已要求开始实现，并补充优先调研国内来源、默认个人非商业用途。下文是原始 backlog 的研究边界，不再用“本轮不实现”阻止当前工作。最新调研见 `06_STOCK_SOURCE_RESEARCH.md`，实际接入与验证状态见 `RESULT.md`；不因“禁止商用”排除允许个人用途的资源。

用户于 2026-09-19 明确：国内外免费图库、付费图库都可考虑；国内外免费/付费视频素材库也可考虑。不要把需求误读为只增加图片生成模型，或只增加免费国外图库。

## 目标

提升素材覆盖、可用性和成片质量；在满足质量、真实性和许可要求下减少不必要生成与费用。不承诺付费库存素材总比生成便宜，也不承诺“免费下载”都能商业发布。

## 下一轮应先做的窄范围调研

每个候选记录：

- 国内/海外、图片/视频、免费/单次购买/订阅，实际采购总成本和币种；
- 官方 API/商业合作接口是否允许搜索、预览、下载和自动采购；无 API 不等于允许抓取；
- 免费许可、署名、商业用途、再分发、人物/商标/财产权限制，编辑用途与商业用途区分；
- 搜索质量、中文查询、国内连通性、分辨率/横竖比例/时长、带水印预览与实际交付差异；
- 预览→购买→实际下载的身份/授权证据、幂等恢复、付费unknown处理；
- 与现有库存、Pexels/Pixabay 等来源的互补性，既有 adapter 能复用多少；
- 搜索结果先免费浏览，用户批准具体费用后才采购；不自动注册账户/订阅；
- 是否可记录来源链接、素材ID、许可版本/获取日期、授权证明和内容SHA，随项目与本地包留存。

先给少量候选比较和推荐接入顺序，再由用户决定供应商/账户/预算；不盲接十几个库。

## 架构边界

复用现有素材搜索/排行、导演路线、provider adapter、素材库、报价与授权、产物身份和复用。库存视频是素材 acquisition 路线，不新建生产工作流；同内容复用须核对使用许可，不把已缓存文件当永久无限授权。

不新增通用采购平台/新的数据库/全网爬虫，不绕水印、不绕下载许可、不拿新闻照片当可商用素材。真实取证类内容不得以生成画面伪装。

本包 P0–P4 已完成的生产决策不因素材扩展重做；素材扩展沿用原工作流，不删除当前已有图片/视频 Provider 和合理费用选项。
