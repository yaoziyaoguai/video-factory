# Model Routing And Semantic Workspaces Design

Date: 2026-08-28

## Goal

在不破坏现有生产任务、模板和 Provider 的前提下，把模型选择从服务器环境变量提升为可解释、可覆盖、可审计的生产配置；同时增加可选的素材语义排序和参考视频制作语法节点，并把节点输入输出从原始 JSON 提升为符合各生产角色工作的可读、可编辑界面。

## Core Decisions

### Provider And Model Are Different Concepts

- Provider 描述鉴权、端点、异步轮询和错误语义，例如 `ark-video`。
- Model Profile 描述具体模型、能力边界、默认参数和保守估价，例如 `doubao-seedance-2-5-260628`。
- Workflow Node 选择生产能力，并可以覆盖本次运行实际使用的 Model Profile。
- `seedance-video-v1` 作为历史 Provider ID 保留兼容别名，不再代表某个固定 Seedance 模型。

模型配置解析顺序固定为：

`system fallback -> global default -> template default -> run override -> node override`

每次执行必须把最终解析后的 Provider、模型、参数来源和计费信息保存为不可变快照。修改总配置不得改变历史任务。

### Model Catalog

模型目录由服务端维护安全能力档案，不把 API Key 或任意 Base URL 暴露给浏览器。每个档案至少包含：

- `id`、`providerId`、展示名称和状态。
- 文生/图生、分辨率、时长、音频等能力。
- 推荐用途、限制、默认参数和保守单次估价。
- 配置来源和是否为当前默认值。

模型发现可以读取供应商模型列表，但能力、价格和可用参数不能仅信任远端自由文本，必须经过本地白名单档案约束。

### Optional Semantic Nodes

1. `asset-semantic-rank` 位于导演方案与素材执行之间。它只重排候选，不下载、不生成、不替换已锁定素材；失败时保留 Provider 原始排序并记录回退。
2. `reference-grammar` 仅在用户提供参考视频时启用。它输出可编辑的 `ShotGrammar`，包含节拍、构图、景别、运镜、光线、色彩、转场、声音结构和可复用制作提示。未提供参考视频时明确跳过。

当前阿里云 4 核 8G、可用磁盘不足以安全部署 WeMM-Embedding 2B，因此语义排序先使用现有 Codex，GLM 只做小规模复核。WeMM 保留为接口兼容候选，不下载安装。

### Resource Manifest

资源清单不是独立法律中心。它是音乐、音效、字体和素材的可追溯元数据：来源 URL、作者、授权类型、商用状态、署名要求、文件哈希和复核状态。旧资源允许字段为空，但新导入资源必须生成清单项。

### Template Experiments

首轮只对 `trend-fact-brief`、`knowledge-explainer` 和 `photo-story` 建立实验评分，不新增更多垂直模板。评分覆盖钩子清晰度、叙事完整度、视觉匹配、声音质量、成本、人工修改次数和最终审片结论。

## Editable Node Workspace

节点工作台继续保留输入、角色与模型、实际 Prompt、输出和执行证据五个区域，但输入与输出默认使用角色化预览和表单编辑：

- 选题/简报：标题、角度、受众、事实边界和成本策略。
- 编剧：开场钩子、逐场旁白、字幕、画面意图和时长。
- 视觉导演：视觉圣经、逐镜目的、检索词、生成提示和模型选择。
- 语义排序：候选缩略图、语义理由、模型分数、原始名次、人工锁定。
- 参考视频分析：节拍时间线、构图、运镜、色彩、声音结构和可复用规则。
- 素材导演：逐镜候选网格、来源、授权、实际模型和替换动作。
- 声音导演：试听、声音演员、语速、停顿和声音处理。
- 审片角色：带时间码的问题、评分、证据帧和修改建议。

高级用户仍可展开完整 JSON。表单保存和 JSON 保存共用同一份 schema 校验与版本服务，AI 原稿不可覆盖。

## Compatibility And Failure Rules

- 历史 Provider ID、模板 ID、任务和 artifact 不迁移或重写。
- 新字段都是可选字段；读取旧数据时生成明确的兼容默认值。
- 模型目录不可用时使用已验证的系统兜底值，不允许模型自行选择任意端点。
- 语义排序或参考分析失败不得阻断免费主流程，但必须显示回退原因。
- 任何按量调用仍在执行前进入费用关卡；模型、参数、输入或预算变化后授权立即失效。
- 未经独立授权不得重新执行已经生成过的付费视频。

## Acceptance Criteria

1. 方舟 Provider 下可以展示和选择多个 Seedance Model Profile；默认模型可从总配置修改。
2. 模板、单次制作和节点可以覆盖默认模型，并按固定优先级解析。
3. 节点页面显示本次实际 Provider、模型、参数、来源层、计费方式和费用快照。
4. Seedance 2.5 使用现有方舟协议完成契约测试，不新增重复 Provider。
5. 素材语义排序具有独立接口、确定性回退、可解释评分和人工锁定语义。
6. 参考视频语法节点可选、输出结构化且可编辑，并能被视觉导演消费。
7. 资源清单和三类模板实验评分可以通过 API 与页面查看。
8. 所有已有节点继续支持输入与输出版本编辑；核心角色使用结构化编辑器而非只能编辑 JSON。
9. 旧任务和旧配置回归通过；本地、浏览器、容器和云端检查通过。
10. 所有实现经过 GLM-5.3-Flash、GLM-5.3 和 Codex 红队审计，已确认问题全部修复后才能发布。
