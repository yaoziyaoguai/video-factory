# Guided Creator Canvas Design

Date: 2026-08-24

## Goal

让第一次进入 VideoFactory 的用户通过真实控件上的聚光灯式点击引导，理解从选题到生产、项目、资源和复盘的路径；同时把首屏从清晰但偏平的工作台提升为有真实影像、导演剪辑台气质的创作界面。

## Product Tour

- 使用 MIT 许可、无运行时依赖的 Driver.js，不自行实现定位、遮罩和键盘控制引擎。
- 首次访问 `/` 且未完成当前版本导览时自动启动。
- 侧栏和移动端标题栏始终提供“使用引导”图标按钮，可从任意页面重播；重播先返回 `/`。
- 完成或跳过都会写入版本化 `localStorage` key。升级导览版本时可以重新触发。
- 导览使用中文按钮、可见进度、键盘控制、关闭按钮和 `prefers-reduced-motion`。
- 导览步骤按真实工作顺序排列：欢迎、候选机会、选题详情、画面方向、导演决策、全局导航、创建创意方案、免费配方、开始生产。
- “创建创意方案”步骤要求用户点击真实按钮继续。下一步等待生产弹窗出现，不自动提交生产任务。
- 导览结束时保留生产弹窗，让用户决定开始或取消。
- 缺失目标元素时跳过该步骤，不让首次体验卡死。

## Visual Direction

- 视觉主题为“导演剪辑台”，不是营销页、节点画布或卡片墙。
- 真实 Pexels 缓存帧提前到选题详情首屏，形成一张主镜头加两张辅助镜头的 contact sheet。
- 镜头上直接显示 shot 编号和用途，画面是信息而不是装饰。
- 标题继续使用 Noto Serif SC，正文使用 Noto Sans SC/Manrope；数字采用稳定的 tabular figures。
- 中性纸面保持可读性，珊瑚红负责创意重点，钴蓝负责主动作，墨绿负责已验证状态，黄色负责当前步骤。
- 导览 popover 使用深色场记板语气、细边框和克制阴影；不使用渐变、玻璃拟态、光斑或超大圆角。
- 选题切换使用短促淡入和轻微位移，`prefers-reduced-motion` 下停用。

## Architecture

- `creator-tour-state.ts` 只负责版本化存储判断，不依赖 React 或 Driver.js。
- `use-creator-tour.ts` 负责路由、Driver.js 生命周期、步骤与重播，不管理业务数据。
- `AppShell` 只渲染两个帮助入口并调用 hook。
- 业务组件只增加稳定的 `data-tour` 锚点，不依赖导览库。
- Driver.js 原始样式单独导入，项目主题覆盖放在 `creator-tour.css`。

## Accessibility And Safety

- 帮助入口有可访问名称和原生 tooltip。
- 引导支持 Escape、上一页、下一页、完成和关闭。
- 聚光灯不会自动触发生产、批准、打回、下载或外部链接。
- 生产弹窗中的最终“开始生产”只被高亮，不由导览点击。
- `localStorage` 不可用时导览仍可启动，只是不记忆完成状态。

## Acceptance Criteria

1. 清空导览 key 后刷新首页，欢迎步骤自动出现。
2. 用户可跳过，刷新后不再自动出现。
3. 点击帮助按钮可从首页或其他路由重播。
4. 导览能要求点击“创建创意方案”，随后聚焦弹窗中的免费配方与开始按钮。
5. 导览不会创建生产任务。
6. 1440x900、768x1024、390x844 均无 popover 溢出或控件遮挡。
7. 首屏无需滚动即可看到真实画面 contact sheet。
8. 前端组件测试、Studio 服务测试、生产构建和浏览器逐步点击全部通过。
