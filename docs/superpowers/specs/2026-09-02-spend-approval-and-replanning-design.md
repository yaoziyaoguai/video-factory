# 逐笔素材报价与手动重规划设计

## 目标

取消整条视频的费用上限和付费镜头数上限。用户只在会产生现金成本的 AI 图片、AI 视频实际执行前，查看基于当前方案的逐项真实报价并决定是否授权。

当用户拒绝素材报价时，系统必须把原因、目标费用和文字意见保存为导演重规划反馈；但不得自动调用导演。用户可以先检查或编辑方案和 Provider 配置，再主动点击“重新规划”。新方案必须覆盖全部镜头，并产生一份新的、独立的报价。

## 非目标

- 不用视频级总额或镜头数截断任何方案。
- 不把目标费用当成硬门禁。
- 不以删除镜头、暗中替换 Provider 或说明卡来降低报价。
- 不把 Code Plan 额度或本地计算伪装成现金扣费。

## 费用与审批语义

`billing` 和 `approvalPolicy` 是两个独立维度：前者保留实际成本账，后者决定是否暂停等待人工。

| 能力 | billing | approvalPolicy | 行为 |
| --- | --- | --- | --- |
| AI 图片、AI 视频素材 | metered | manual | 根据完整导演方案逐项报价，人工授权后才能调用 |
| 配音 | metered | automatic | 不弹报价，不中断制作；仍在回执和成本看板记录真实费用 |
| GLM Flash 5.3 视觉审片 | subscription | none | 使用 Code Plan 额度，不产生现金报价或授权 |
| 免费图库、本地编辑、渲染、技术质检 | free 或 local_compute | none | 不产生现金报价或授权 |

所有新的 `metered` Provider 默认 `manual`，只有被明确列为 `automatic` 的低风险能力才能跳过人工授权。`SpendPlan.maxCostCny` 保留，但只表示该次不可变报价的“本次最高授权扣费”，绑定输入版本、Provider、模型、报价条目与重试次数，绝不是视频预算。

## 素材报价与拒绝状态机

1. 导演为全部脚本场景给出可执行的素材方案。
2. AI Router 按实际选中的图片/视频 Provider、模型、时长和镜头逐项生成报价；没有现金素材时不创建审批节点。
3. 用户确认后，只有与该报价完全匹配的输入、Provider、模型和重试范围可以执行。
4. 用户拒绝后，系统持久化 `reason`、可选 `targetEstimatedCostCny`（允许 `0`）和 `note`，作废旧报价与导演/素材下游结果，并停在“待手动重规划”状态。
5. 用户点击“重新规划”后，导演收到最近有限历史的反馈；最新反馈优先，但所有反馈都只是优化偏好。导演仍必须输出完整镜头方案。
6. 系统生成新的真实报价，重新等待人工确认。

配音等自动审批成本节点不进入导演反馈路径；其成本记录保留，若需要调整，由用户修改该节点的 Provider/模型后重新执行。

## 素材完整性与失败

说明卡只在导演显式选择 `local-editorial-v1 + editorial_card` 时允许，并且可见文案不得包含“门禁拦截”“待证据核验”等内部工作流状态；命中时宁可让素材节点失败并等待重规划。图库搜索、下载、生成调用、轮询、媒体下载、文件描述或母片复用失败都必须使素材节点失败，不能继承本地占位卡的成功状态。

`REUSE_ONLY` 是母片引用，不是图库搜索或新的生成任务：复用镜头不计费、不提交生成任务；母片成功替换后所有直接和间接复用镜头跟随同一最终素材；母片失败时依赖镜头一起失败。

最终成功的素材计划必须恰好覆盖全部脚本场景，不能包含 `generation_pending`、失败生成任务、未授权本地卡片，或不再被最终计划引用的旧卡片 artifact。

## UI

- 新建制作和模板不展示“预算上限”或“付费镜头上限”；制作配方只决定可用能力组合。
- 图片/视频报价展示总价、逐项镜头、Provider、模型和本次最高授权扣费。
- “这份报价不合适”只保存反馈并显示“待手动重规划”；按钮不会在后台调用导演。
- 重规划后仍需查看新报价并重新确认。
- 视觉审片标为 Code Plan 额度；配音只在成本账中可见，不显示现金审批弹窗。

## 兼容与验证

旧请求、模板和快照中的 `maxCostCny`、`maxPaidShots` 可被解析以兼容历史数据，但必须归零且不得影响导演、素材执行、模板展示或资源治理指标。

回归测试至少覆盖：

- 每个计费图片/视频镜头都在授权前阻止外部调用；配音可自动执行并留下成本回执；GLM 审片不创建 SpendPlan。
- 拒绝报价不会调用导演；手动重规划才会调用导演，并收到完整反馈历史；目标 `¥0` 可解析。
- 报价变更、输入变更、Provider/模型变更或重试范围变更会让旧授权失效。
- 非明确 editorial 的本地卡、待生成资产、失败 job、缺失镜头和错误复用链都会阻止素材节点成功。
- 桌面和移动端均能完成“查看报价 → 反馈 → 手动重规划 → 新报价 → 确认”的流程。
