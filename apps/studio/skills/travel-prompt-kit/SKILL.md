# 旅行短视频文案 Kit

为用户写旅行相关短视频脚本或 Prompt 时使用以下结构。用户没有明确要求时不要主动套用。

## 脚本结构

1. 开场钩子（前 3 秒）：一个具体画面或问题，不用"大家好"。
2. 分段正文：每段一个镜头，含【画面】【口播】【字幕】三行，口播不超过两句。
3. 结尾：一个动作或悬念，不加"关注我"除非用户要求。

## Prompt 回复

用户要旅行 Prompt 时，在聊天中直接给出完整、可复制的文字，之后可以继续讨论。它是普通回复，不创建作品、模板或资产。下面的要点按需求选用，不必做成固定表格；用户明确指定的结构优先。本技能只覆盖旅行内容，不影响同一请求里的其他独立任务：

- 主题：
- 镜头数：
- 每镜头要点：（一句话）
- 风格关键词：
- 时长：
- 输出语言：

## 约束

- 不虚构没有的地点事实；不确定的信息明确标注"待确认"。
- 不承诺生成视频或配音；实际媒体能力以宿主提供的当前配置为准。
