# 通用视频生成技能

当用户要求生成新视频镜头、规划分镜画面或准备整批视频制作提案（且未专门锁定单一渠道技能）时使用本技能。纯本地剪辑已有素材或重混音轨直接使用 `render_project`，不发起新模型生成。

## 模型池选型规则（厂商 API 与算力通道并列）

1. 先读取本回合 `[frame-current-state]` 中的 `mediaModels`（筛选 `kind === "video"` 且 `availability === "configured"`）：
   - **对话点名优先**：若用户在本轮消息中明确指定了连接名、厂商或型号（如「用 Colab LTX-2.5」「用主账号 Seedance」「用万相」），优先绑定对应的 `ModelBinding`，并在该操作上传入 `modelSource: "user_named"`；若点名渠道尚未启用或参数不满足（例如 Colab 缺少单张首帧图或请求了非 5 秒时长），如实说明原因并列出当前池内可用选项，绝不暗自替换成其他渠道。
   - **沿用配置默认**：若用户未点名具体模型，优先选用 `isDefault === true` 的视频条目（`modelSource: "default"`）；生成提案后，用户可在提案卡片上亲眼核对默认连接、型号与费用，也可直接在卡片内一键切换整批或单镜模型。
   - **池内无默认时**：若池内有可用视频模型但 `isDefault` 全部为 `false`，先向用户简要列出池内可选的连接与型号，或在不伪造用户点名的前提下准备待选提案（不传 `user_named`），由用户在提案卡片中明确选定模型后再开始制作。
   - **池为空时**：如实引导用户前往「模型配置」启用视频连接与型号。

## 各渠道能力边界核对

- **火山方舟 Seedance 2.5**：`4–30` 整数秒、`720p`、`16:9`（带参考图或首尾帧时按首帧画幅自适应），支持文生视频、首尾帧与最多 30 张参考图，支持 `none` / `native` 音频，按秒估算人民币费用。
- **阿里万相 3.0**：`2–30` 整数秒、`720P`、`16:9`（支持最多 10 张参考图），支持 `none` / `native` 音频，按秒估算人民币费用。
- **MiniMax H3 / H3-Max**：`4–15` 秒（H3-Max 为 `5–15` 秒）、`768P`、原生音画（`audioMode: "native"`），最多 9 张参考图，按秒估算人民币费用。
- **Google Colab（Lightricks/LTX-2.5-distilled）**：固定 `5` 秒、`720p`、`16:9` 或 `9:16`，**必须提供单张冻结首帧图（`firstFrameSlot`）+ 连续动作提示词**，支持 `none` / `native` 音频；消耗 Google Colab 计算单元（`CU`），人民币 API 扣费为 `¥0.00`（同批多镜自动热复用 GPU 实例）。

## 镜头提示词与确认门

1. 每镜聚焦单一连续主体运动、清晰运镜方向与光影细节；含独立旁白时将完整逐字旁白写入方案 `narrationText`，需要新生成配音时与视频一同放入同一次 `prepare_production`（无论付费配音还是 Edge 免费配音均经同一提案确认）。
2. 提案准备完成后，引导用户在提案卡片上核对默认/所选模型与费用并点击确认按钮，停下来等待用户确认，绝不在确认前发起任何真实媒体生成。
