# 交互样稿素材

PNG 图片和原始短 MP4 复制自已确认原型的本地 `ui-prototypes/video-agent-open-conversation-20261024/assets/`；原目录未修改。这些素材只用于本地交互示例，不作为本次供应商执行结果或素材匹配证据。

`narration.mp3`、`coffee-narration.mp3` 由本机 macOS 系统语音生成。`trail-preview.mp4` 由两段六秒示例片段和八秒静态图组成，总长 20 秒；咖啡示例使用本地咖啡片段循环至 20 秒。两个 `-silent.mp4` 是对应的无声版本。均由本地 FFmpeg 处理，没有外部生成、下载或付费调用。

文件仅由独立 preview.html 的模块导入，正常应用入口不引用。用户确认交互后，保留的是产品选择与测试场景；模拟状态逻辑、示例价格和媒体不能直接当作生产实现。
